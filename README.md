### Image Gallery

Developed a responsive **Image Gallery website** using **HTML, CSS, and JavaScript** to display and organize images in an attractive and user-friendly layout. The project provides an interactive way to browse and view images easily.

**Key Features:**

* Responsive gallery layout for different screen sizes
* Attractive grid-based image display
* Image preview and viewing functionality
* Smooth hover effects and interactive elements
* Simple and user-friendly interface
* JavaScript-based image interactions and navigation
